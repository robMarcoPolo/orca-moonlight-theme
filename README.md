# Moonlight for Orca

An unofficial port of [Moonlight II](https://github.com/atomiks/moonlight-vscode-theme) by atomiks to
[Orca](https://orca.dev). Not affiliated with or endorsed by the original author.

- Moonlight II (dark)
- Moonlight II Italic (dark): the same colours, with italic comments, keywords and attributes

Each theme colours Orca's interface, the code editor (`tokenColors`) and chat, and the plugin adds
a matching **Moonlight II** terminal palette.

## Install

In Orca, open Settings → Plugins, search for **Moonlight for Orca** and choose Install, then pick
**Moonlight II** under Settings → Appearance → Dark theme. The **Moonlight II** terminal palette is
offered under Settings → Terminal.

From source: Settings → Plugins → **Development folders…** and add a clone of this repository.
